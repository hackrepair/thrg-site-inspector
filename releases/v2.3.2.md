# thrg-site-inspector 2.3.2

- The account check now looks at the newest administrator-level accounts first, so a recently added admin is not skipped on large sites.
- Added PHP 8.5 to the supported-version check.
- Update details from GitHub are cleaned before WordPress shows them.
- Reply-To names in emailed reports are quoted safely.
- View Details reads its requirements from the readme and no longer shows a misleading last-updated date.
- Deleting the plugin with *Delete all plugin data* ticked now also removes the update checker's saved data.

No changes to saved settings or report history. Older releases are retained.
