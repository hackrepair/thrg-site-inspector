# Site Inspector 2.5.1

Monitoring now shows the time, alert type, and accepted/failed counts for the latest email attempt. Acceptance does not confirm delivery. Turning monitoring off clears this status.

Other improvements:
- Copy feedback now handles failed clipboard attempts cleanly instead of reporting success when copying is blocked.
- Printed reports omit the monthly email and change monitoring settings panels.
- Mobile headings use the intended 24px size.
- Removed the unused legacy logo file and updated updater docblock types.
