# thrg-site-inspector 2.4.0

- **Monthly security email.** On a day you choose, Site Inspector checks the site, saves the report and emails the statement to all administrators or the ones you pick. Off until you turn it on. Send every month, or only when something needs fixing or a second look. Subjects say *Monthly Security Check*.
- The *Send this report* section shows whether the monthly email is on, with a link to set it up.
- **PHP security fixes.** The PHP version check now says when the site runs a PHP version older than the release that fixes a known flaw, starting with PHP2Shell (CVE-2026-109618 and CVE-2026-109619, fixed October 21, 2026). Operating-system PHP packages are marked for review, since they often carry the fix under the old version number.
- The PHP check says when its built-in list of PHP security fixes is more than 90 days old.

No changes to existing settings or report history. Older releases are retained.
