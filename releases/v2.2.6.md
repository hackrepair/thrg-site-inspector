# 2.2.6

Fixed a packaging defect that could leave Site Inspector unstyled on live hosting. The 2.2.5 ZIP preserved owner-only (0600) permissions on inspector.css, causing HTTP 403 responses when the web server runs as a different user.

The release builder now assigns 0644 permissions to every packaged file and validates them. Added an isolated regression test using restricted source files. Plugin functionality and styling content are unchanged.

Validation: permissions regression, shared PHPCS, existing PHP tests, packaged PHP syntax, ZIP integrity, complete updater dependencies and source/package byte correspondence.
